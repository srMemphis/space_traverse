# space_traverse

Simulates the charging of dielectric Targets by an electron Beam: every Iteration solves the Potential on a tetrahedral mesh, traces Tracks through the Field and deposits the absorbed charge. Terms are defined in [CONTEXT.md](CONTEXT.md).

## Requirements

- Windows x64.
- Visual Studio 2026 (toolset v145).
- Python 3, only for the smoke check in [`tools/smoke`](tools/smoke).

## Build

1. Run [`generate_vs2026.bat`](generate_vs2026.bat) and open `build/space_traverse.slnx`. From a Developer shell you can build without the IDE: `msbuild build/space_traverse.slnx /p:Configuration=Release /p:Platform=x64`.
2. Pick a configuration:
   - `Debug`: unoptimized, for debugging.
   - `Profile`: optimized, with the profiler on; it writes `profile.json`.
   - `Release`: maximum speed, for Runs you keep.

Tests are the `space_traverse_core_tests` project, built to `build/<Config>/space_traverse_core_tests.exe`.

Code style is set by [`.clang-format`](.clang-format) in the root; vendored `space_traverse/include` and `space_traverse/lib` are excluded.

## Run

The program reads `config.yaml` from the working directory. For the `space_traverse` startup project that is [`space_traverse/`](space_traverse), which is how the debugger is set up.

**Warning:** the directory named in `General.outdir` is deleted entirely at startup.

## Repository layout

- [`space_traverse/src`](space_traverse/src): source code of the core library.
- [`space_traverse/app`](space_traverse/app): `main.cpp`.
- [`space_traverse/tests`](space_traverse/tests): doctest unit tests.
- [`space_traverse/include`](space_traverse/include), [`space_traverse/lib`](space_traverse/lib): third-party libraries, vendored; don't edit them.
- [`space_traverse/msh`](space_traverse/msh) (Gmsh `.geo` sources in [`msh/scripts`](space_traverse/msh/scripts)) and [`space_traverse/configs`](space_traverse/configs): built-in meshes and Scenarios.
- [`space_traverse/scripts`](space_traverse/scripts): MATLAB visualization scripts.
- [`tools/premake`](tools/premake): premake 5.0.0, which generates the build.
- [`tools/smoke`](tools/smoke): smoke check that compares the output of two builds.
- [`docs`](docs): project documentation.
- `build/`: generated by `generate_vs2026.bat` and by the build; not in git.
